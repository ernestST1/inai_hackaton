# Осенний хакатон INAI 2026 — пакет участников
Версия 1.1 • 20 ноября 2026

1. Прочитайте TASKS_ORIGINAL_RU.docx и CLARIFICATIONS_RU.md.
2. Выберите одно из 7 заданий и откройте его папку 01_sms…07_coverage.
3. Используйте открытые данные и опубликованные эталоны для разработки. README в каждой папке объясняет состав.
4. Подготовьте репозиторий с одной командой запуска и инструкцией вызова функции/CLI/API. Сетевые ключи и реальные SMS не требуются для обязательной части.
