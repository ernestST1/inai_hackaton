# ТЗ 3 — USSD
subscribers.json: 10 абонентов. packages.json: D1, D5, M50. Поле remaining — стартовые остатки, transferred_today_som — уже переведённая за день основная сумма.
scenarios_examples.json: 5 открытых сценариев со смыслом ответа, состоянием и временем. Каждый начинается с чистой фикстуры, а не продолжает предыдущий. Виртуальные часы — описание ожидаемого поведения, не требование добавить HTTP-метод управления временем. Можно проверять с реальными ожиданиями.
Тексты меню свободные. Скрытые сценарии проверяют семантику и числа, а не точное совпадение строки.
