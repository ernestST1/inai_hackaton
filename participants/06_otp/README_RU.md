# ТЗ 6 — OTP
test_identities.json: 50 синтетических номеров и 2 документационных IP для локальных испытаний. Здесь нет готовых настоящих кодов: их генерирует сервис команды.
scenarios_examples.json: 5 открытых сценариев. capture_delivery означает перехват SMS в тестовом транспорте, $c1 — код из этой доставки, $wrong:c1 — заведомо другая шестизначная строка. Это не чтение журнала безопасности и не публичный метод получения кода.
Доставка «SMS» для испытаний: сервис дописывает каждую выдачу одной строкой JSON `{"ts": "2026-11-21T09:00:00+06:00", "msisdn": "996770730000", "code": "012345"}` в файл `outbox/sms.jsonl` в корне репозитория (путь можно переопределить переменной окружения `OTP_OUTBOX`). Это имитация SMS-шлюза, а не хранилище сервиса: сервис этот файл не читает. capture_delivery в сценариях жюри — последняя строка этого файла для номера.
Время указано относительно начала независимого сценария. Допускаются подменяемые часы в тестах либо реальные ожидания. Никогда не проводите учебную атаку на внешнем сервисе.
