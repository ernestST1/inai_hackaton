# Эфир — карта покрытия Бишкека

Решение ТЗ № 7. По замерам RSRP «Эфир» строит сетку 200 × 200 м, находит три ячейки с самым слабым сигналом и выбирает две площадки для новых базовых станций.

**[Скачать финальный проект в ZIP](https://github.com/ernestST1/inai_hackaton/archive/refs/heads/master.zip)**. Распакуйте архив и откройте `signal-atlas/dist/index.html` в браузере. Карта работает офлайн, все необходимые файлы уже встроены в HTML.

## Результат на наборе участников

Из 5 000 строк принято **4 800**, отброшено **200**. На карте 387 ячеек с пятью и более замерами, из них 174 слабые. Расстояние от новой станции до центра покрытой ячейки — до 1 км. Ячейка в пересечении двух радиусов считается один раз.

| Алгоритм | Площадки | Покрыто слабых ячеек |
| --- | --- | --- |
| Полный перебор 120 пар | **C09 + C14** | **111 из 174** |
| Жадный выбор | C16 + C17 | 108 из 174 |

Переключите алгоритм над картой, чтобы увидеть разницу в три ячейки. Для сравнения покрытия по времени выберите день или ночь. Слой **Запретные зоны 500 м** показывает, какие площадки оказались слишком близко к существующим станциям. Улицы Бишкека взяты из OpenStreetMap через сервис terrestris. Радиозамеры и станции относятся к учебному набору. [Результат для жюри](signal-atlas/dist/result.json) · [Картографический источник](https://terrestris.de/produkte/free-osm-wms/)

## Как воспроизвести расчёт

Выполните команды из корня распакованного проекта с Node.js 20 или новее. Для тестов и обработки CSV достаточно стандартной поставки Node.js.

```sh
cd signal-atlas
node --test
node scripts/analyze.mjs --data data/07_coverage --out output
```

CLI создаст `signal-atlas/output/index.html` и `signal-atlas/output/result.json`. В тестах расчёт из исходных CSV и готовый JSON сверяются с открытым эталоном. [Входные данные](signal-atlas/data/07_coverage) · [Эталон](signal-atlas/data/07_coverage/expected.json)

Для скрытого набора замените значение `--data` на путь к папке с `measurements.csv`, `towers.csv`, `candidates.csv` и `bounds.json`. В браузере те же файлы можно выбрать через **Загрузить CSV**.

Алгоритм очистки, правила сравнения площадок, структура модулей и команды сборки описаны в [README проекта](signal-atlas/README.md).
