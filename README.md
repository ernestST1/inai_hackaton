# Эфир — карта покрытия Бишкека

Решение ТЗ 7 по набору участников. Для просмотра скачайте [HTML-карту](signal-atlas/dist/index.html) и откройте её в браузере. Она работает офлайн. Площадки **C09 и C14** вместе покрывают **111 из 174** слабых ячеек. [Результат расчёта](signal-atlas/dist/result.json)

Улицы на карте взяты из OpenStreetMap через картографический сервис terrestris. Чтобы сверить район, нажмите **Открыть в OpenStreetMap** под картой. [Картографический источник](https://terrestris.de/produkte/free-osm-wms/)

## Проверка

Из корня репозитория выполните команды с Node.js 20 или новее. Установка пакетов для расчёта и тестов не требуется.

```sh
cd signal-atlas
node scripts/analyze.mjs --data .. --out output
node --test
```

Первая команда пересчитывает карту и JSON из трёх CSV и `bounds.json` в корне репозитория. Тесты проверяют открытый эталон и граничные случаи. Описание алгоритма, бонусов и порядка чтения кода — в [инструкции проекта](signal-atlas/README.md).
